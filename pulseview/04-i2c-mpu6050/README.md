# I2C (Webinar 4) — логічний аналіз

**Що міститься:** скріншоти PulseView з курсорами (png).


**Пояснення по скріншоту `pulse_view 1.png`:**Перемикач не має позначень ON/OFF. Під час тестування стан «FAULT ON» визначався за положенням повзунка, однак аналіз сигналу на шині показав, що фактично це був нормальний стан (0x68 + ACK).

**Пояснення по скріншоту `pulse_view 2.png`:** Після активації FAULT з'являється одиничний NACK на адресі 0x69. Після цього обмін даними по шині I2C припиняється. Повернення FAULT до нормального стану не відновлює роботу системи. Зв'язок не відновлюється, і лише перезапуск пристрою дозволяє відновити роботу.
